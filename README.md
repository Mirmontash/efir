# Атлас эфира — офлайн-версия

Личное веб-приложение: карточки о видах эфира со статусом научной проверки, таймлайн, карта со своими связями, материалы по Виктору Ефимову и дневник анализа.

Записи дневника и связи хранятся только в браузере на устройстве (localStorage) и в репозиторий не попадают. Резервная копия: «Дневник → Экспорт JSON».

На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».
