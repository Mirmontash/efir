# МЭфир — офлайн-версия

Личное веб-приложение: досье по видам эфира (лица, иллюстрации с указанием источников, бриф с достоверностью и перспективами), шкала достоверности, галерея людей, таймлайн, карта со своими связями, материалы по Виктору Ефимову и дневник анализа.

Записи дневника, связи и отметки «изучено» хранятся только в браузере на устройстве (localStorage) и в репозиторий не попадают. Резервная копия: «Дневник → Экспорт JSON».

Иллюстрации — из Wikimedia Commons (общественное достояние или CC), авторы и лицензии в `img/credits.json` и под каждой картинкой.

На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».
